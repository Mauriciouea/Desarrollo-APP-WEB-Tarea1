# Sistema de Administración - Soluciones Digitales

Sistema web de gestión empresarial desarrollado con Flask y MySQL.

## Características
- Registro y login de usuarios
- Dashboard administrativo
- Gestión de productos, clientes, proveedores
- Facturación con control de stock
- Impresión de facturas

## Instalación

1. Clonar el repositorio
2. Crear entorno virtual: `python -m venv venv`
3. Activar: `venv\Scripts\activate` (Windows)
4. Instalar dependencias: `pip install -r requirements.txt`
5. Copiar `.env.example` a `.env` y llenar las credenciales
6. Ejecutar: `flask run`

## Tecnologías
- Flask
- SQLAlchemy
- MySQL
- Bootstrap 5
